# 引擎设计原则
- 音画同源：物理模拟先跑出一份事件日志（时间、对象、位置、速度、强度、音高序号），画面和声音都读这一份日志，碰撞音与画面严格同步。
- 渲染是帧号的纯函数，随机数用固定种子，重跑结果一致。
- 一切可调：分辨率、粒子数量、调色板、节奏。画幅默认 16:9，另提供 9:16 版面配置（只调整镜头取景和字幕位置，粒子与物理不变）。
- 调色板做成可切换预设：「深海夜」（底 #0A0D16，白色细线，彩虹色爆发）和「撞色块」（炭灰底，钴蓝 #2F5BEA / 朱红 #E5533D / 芥末黄 #E8B931 / 墨绿 #2E7D5B）。本片用「深海夜」。
- 后期：泛光、冲击帧 2–3 帧色差分离、轻微噪点与暗角、冲击震屏。
- 声音：numpy 合成，不用外部素材。分轨输出 sfx.wav、music.wav、mix.wav，方便以后换 BGM。
- 风格原则：前半克制（近乎单色、细线、少量点），后半一次性彩色爆发，爆发感来自反差。每幕至少一次光带扫过，镜头始终缓慢运动。
- 字幕：粗宋体（Noto Serif CJK SC Bold），大字，白色，居左偏下，关键词（文案里用 **…** 标出）用强调色；数学符号字体回退到 DejaVu，避免显示方块。
- HUD：左上角小号英文大写标签 + 左侧细竖线，右上角等宽字体计数器。右侧留 6% 边距。

# 本片语义色
灰色 = 有理数 = 问候气泡；芥末黄 = 无理数；钴蓝 = 「那一层」；朱红仅用于「不可积」印章和冲击强调。

# 分镜与文案（约 64 秒，文案放入 script.json，逐句出现）
【0–4s 钩子】预设 chat_bubble_storm
第一帧就有冲击，不要淡入。数百个灰色微信风格气泡（只用通用问候语：在吗 / 早安 / 吃了吗 / 睡了吗 / 在干嘛 / 哈喽；绝不出现真实昵称、头像或聊天截图）从四面涌向镜头，密到没有缝隙。字幕第一帧出现。
字幕：「有一种消息，每天都到。」「一条都**没有分量**。」
声音：密集、细碎、很轻的提示音，像雨。

【4–14s 稠密】预设 dirichlet_field
画面变为数轴上的点阵：灰色小气泡（有理数）与芥末黄点（无理数）交错闪烁，镜头连续放大两次，密度不变。HUD「DIRICHLET · 1829」。
字幕：「数轴上，有理数处处都是。」「无理数，也处处都是。」「任意一小段，两种都有。」
声音：高频细碎的闪烁，随放大音高上升。

【14–22s 可数】
灰色气泡被逐个标上序号 1、2、3……，右上角出现「μ(ℚ∩[0,1]) = 0」。
字幕：「但有理数，能一个一个数出来。」「数得出来的点，长度加起来是 **0**。」
声音：节拍器式的轻微 tick。

【22–28s 黎曼】预设 riemann_bars_collapse
竖直柱子从左到右升起，试图贴合函数，剧烈抖动后塌掉，印章「不可积」重重落下，震屏 + 色差。HUD「RIEMANN · 1854」。
字幕：「黎曼按顺序看，分不出轻重。」「他的积分，到这里失效。」
声音：钝响 + 轻微失真。

【28–34s 勒贝格】预设 banknote_sort
乱序钞票色块按面额分成几摞（约 2 秒），然后回到点阵，切法由竖切变成横切。HUD「LEBESGUE · 1902」。
字幕：「勒贝格不按顺序，**按分量**。」「同面额的放一堆，再数。」
声音：纸张沙沙声。

【34–44s 结算】预设 bubbles_to_light
灰色气泡逐个缩成光点熄灭；琥珀色点保留并铺满；计数器滚动，定格在「∫ = 1」。
字幕：「结果是 **1**。」「每天都到的，一分不占。」
声音：熄灭音逐个下行，定格时留约 0.5 秒静默。

【44–56s 那一层】预设 voice_bubble_to_slab、slab_tower
一条标注 60″ 的钴蓝色语音气泡出现，横向展开成板层（宽度对应 60 秒）；字幕以文字呈现，不做 AI 配音。随后板层长出高度，一块块叠成钴蓝色的塔，镜头绕塔旋转半圈。角落小号公式：∫ f dμ = ∫₀^∞ μ({f>t}) dt（照抄，不改写）。
字幕：「有人，很少发消息。」「这个月生活费，还够不够花？」「提成发了，第一个就想着转给你。」「勒贝格算分量：高度乘宽度。」
声音：温暖低音垫入；每升一层加一个音，音高逐层上升；塔成时落一个和弦。

【56–64s 收尾】预设 particle_text
所有粒子起飞，拼成大字「几乎处处」，光带扫过，下方小字 almost everywhere，静止约 1.5 秒。最后 2 秒左上角小字「测度论笔记 · 01」。
字幕：「次数，不在公式里。」「几乎处处——除了测度为零的地方。」「**频率，和分量，是两回事。**」
声音：长和弦渐弱。

# 数学准确性（不要自行改动）
- 狄利克雷函数：无理数处取 1，有理数处取 0；勒贝格积分在 [0,1] 上等于 1；黎曼积分对它不可积
- 有理数处处稠密但可数，测度为零。画面不得暗示"有理数与无理数一样多"，只表现"每一小段里两种都有"
- "数钱"的比喻出自勒贝格本人，可以使用
- 层饼公式照抄；"几乎处处"的含义是「除了测度为零的集合，处处成立」，不是「大部分时间」
