## 1. 镜头时间表（按拍网格）

### 1.1 单位 U 的选择：**6 拍**（不选 4 拍）

- **实测节拍**：`bgm_analysis.json` 的节拍序列在 20–110 s 内线性拟合，拍间隔 0.5314 s（≈112.9 BPM，最大残差 18 ms，非常稳）。**U = 6 拍 = 3.188 s。**
- 选 6 拍而不是 4 拍的理由：
  1. **字幕停留正好对上整数个 U**：bottom 每句 ≥3.2 s ≈ 1U（实际显示 1U + 0.1 s 交叠 = 3.29 s），headline 5–7 s = 2U（6.38 s），center ≈3 s = 1U。用 4 拍（2.13 s）的话停留要取 1.5U，镜头与字幕对不齐。
  2. **与参考视频的镜头长度一致**（其镜头长度也是 6 拍的整数倍），这是我们要借的节奏结构。
  3. 代价：BGM 的和弦 4 小节一循环（16 拍），6 拍网格的切点会交替落在「小节首拍」和「小节第 3 拍」，不会每次都卡和弦变化；但切点只要求落在拍点上，不要求落在和弦变化点，可以接受。
- 总长 **24U = 76.52 s**（在 70–80 s 内）。

### 1.2 BGM 窗口

- 「化尘开始」放在 BGM **最强上扬**处（`bgm_analysis.json` 里可行候选中最强的一次：原曲第 93.563 s 的起音，从 −13.5 dB 的低谷段回到满强度；全曲最强的一次在第 17 s，但它前面不足以放下 21U 的铺垫，仍不可行）。
- 化尘开始 = **第 21U = 视频 66.95 s**；BGM 窗口起点 = 93.563 − 66.953 = **原曲第 26.61 s**，窗口终点 103.13 s。淡入 1.5 s / 淡出 3 s 沿用。
- BGM 能量与画面对位：视频 0–52.3 s = 原曲 26.6–78.9 s（主段，−8 ~ −10 dB）；**视频 52.3–67.0 s = 原曲 78.9–93.6 s 的低谷段（−12 ~ −13.5 dB）**，正好覆盖「那一层」的安静段与逐层点亮；67.0 s 起音处 = 化尘开始。

## 3. 六项借鉴的落地

**1. 镜头按拍网格排** —— 全片 24U、切点 k·U、提前拍点 28–47 ms（见 1.3）；BGM 窗口起点按「化尘开始 = 21U」重选（原曲 26.61 s）。落到本片：场景脚本的镜头起止全部重排；各预设内部的局部时间轴要按新长度重标（黎曼、钞票 / 气泡分堆、熄灭、塔点亮、化尘）。**改现有**（场景脚本 + 预设参数；音频侧是 `bgm_mix.py` 的窗口参数）。

**2. 字幕三层** —— 在字幕层引入 headline / center / bottom 三种样式：headline 上部居中、字高 8%、停留 2U；center 屏幕中央、字高 12%、强调色发光；bottom 底部居中、字高 3.5%。三句语音字幕放 headline（最想让人记住的）。**新做**（`engine/web/text.js` 要加 `layer` 渲染分支，这是引擎改动，我会保持向后兼容：没有 `layer` 字段时仍按现有样式；`script.json` 加字段）。

**3. 闪白切** —— 全片 4 处（2U / 9U / 13U / 15U），灰白峰值 ≤70% 亮度、峰值约 3 帧、总长 ≤0.15 s，新场景主元素在闪白褪到一半时才显影；该帧关闭泛光。落到本片：写一个场景内的「flash_cut」预设，在切点帧逐帧写入闪白量（不用引擎现有的指数衰减，那条曲线拖得太长）。**新做**（场景内预设，不动引擎）；各镜头的 `fadeIn` 加延迟让显影晚于闪白峰值。

**4. 运动量预算** —— 安静段两处（5–9U、17–19U）：主元素静止，相机漂移关掉，只靠字幕与 HUD 更新；运动集中在切点前后 1–2 s（蓄力 → 释放）和两段连续运镜（放大、拉远）。落到本片：给点阵与塔加「静止」开关、给场景相机函数分段；并用参考视频拆解里的同一套帧差脚本对新预览测一遍（安静段帧差 <0.3，与参考的静止段同量级）。**改现有**（参数 + 场景相机函数）。

**5. 色彩纪律** —— 背景改为近黑 #08090E；强调色只有琥珀（沿用「其余的时间」的黄）和冷冰蓝（沿用语音塔的蓝），灰色气泡保持中性；色温由暖变冷（S2 琥珀为主 → S6 蓝塔）；「不可积」印章改为琥珀发光线框；钞票面额色去掉绿色，改用灰 / 琥珀 / 蓝 / 白；**彩虹只留在逐层点亮 → 化尘一处**（色相 = 高度）。落到本片：场景里覆盖调色板的背景色与钞票色；印章需要一个新的线框发光画法。**改现有 + 新做小件**（印章线框变体）。

**6. 声音改为「音乐为主」** —— 取消气泡 / 闪烁 / tick / 熄灭等逐事件音效，只留 ≤6 处关键时刻：① 2U 切点；② 印章落下（「不可积」）；③ 15U 切点（进入「那一层」）；④ 塔逐层点亮（8 个音沿当下和弦音上行，算一处）；⑤ 化尘开始；⑥ 聚字成型。混音：整体 ≈ −10 LUFS、真峰值 ≤ −1 dBTP、LRA ≤ 3 LU，取消分段电平，音效触发时 BGM 最多压低 2 dB；音高仍按「调式 → −25 cents → 当下和弦 → 色度前 5 自检」。可选：化尘前对 BGM 做缓慢低通（只在 mix.wav 里做，`bgm_trimmed.wav` 保持纯净），化尘开始时打开——这条请你定要不要。**改现有**（`bgm_mix.py` 新增「音乐为主」模式，旧模式保留）。`Luv4.flac` 只读、sha256 前后比对不变。

## 4. 工作量与风险

- **工作量**：画面部分最大的两块是「三层字幕的引擎改动 + 场景全量重排」和「闪白 / 印章 / 静止开关这几件新做的小预设」；音频部分是在现有脚本上加一个模式，另需重新跑一遍 BGM 色度 / 和弦对位（窗口起点变了）。画面总长从 64 s 增到 76.5 s，540p 预览渲染时间会相应变长。
- **风险 / 需要你拍板的点**：
  1. **bottom 字高 3.5%**：约为现在（A4 里按「手机上能读清」放大后的 8.6%）的 40%。参考视频是这个比例，但在手机上可能偏小；如果你更看重可读性，我建议 bottom 取 4.5–5%，请确认。
  2. **压缩到 2U（6.4 s）的三个镜头**（黎曼、钞票 / 气泡分堆、熄灭）：原来分别用 5 s / 8 s / 10 s，压缩后动画会偏紧，尤其钞票与气泡分堆；我会收紧各预设的内部节奏，但仍可能需要你在预览里再看一轮。
  3. **headline 8% 的位置**：与现有「60″ × 满格」标注、左上 HUD 标签有重叠风险，需要把标注下移或收窄，静止塔的构图要重排一次。
  4. **闪白硬约束**（≤70%、≈3 帧、≤0.15 s、无泛光）：540p / 24 fps 下 0.15 s 只有 3.6 帧，必须逐帧控制；闪白用在 4 处，若你觉得第 4 处（15U 进入「那一层」）太密，可降为 3 处。
  5. **LRA ≤ 3 LU + −10 LUFS + 真峰值 ≤ −1 dBTP**：BGM 自己在「低谷段 → 上扬」有约 4 dB 的落差，响度范围被压到 ≤3 LU 会让这个对比变小，且为达到 −10 LUFS 需要加限幅器，可能削弱化尘处的冲击感；我会在第 3 步先测当前混音的 LUFS / LRA / 真峰值再给调整方案。
  6. **删句**取决于你的选择（第 2.2 节）；`script.json` 里新增的 `layer` 字段需要同步修改文案校验（三句语音字幕与数学句文字不变）。
